# ParcoursIA

Site démo du parcours formation IA Microsoft France — VivaTech 2026.

**Live :** https://nricl.github.io/ParcoursIA/

## Le parcours en 3 actes

1. **Sensibiliser** — Donner à tous la nouvelle littéracie (3 piliers : IA & mise en pratique avec France Travail, data & IA avec Forvia/AI Literacy, IA responsable avec les Cafés IA)
2. **Passer à l'action** — À vous l'IA, l'agent conversationnel pour les PME avec 1 000 cas d'usage
3. **Former des talents** — Écoles IA Microsoft × Simplon, le diplôme RNCP 6 Développeur IA
